# Перенос архива на Beget

1. Сохраните резервную копию базы и файлов (Система → Создать backup), скачайте её.
2. Распакуйте chgpu-archive-migration.zip в корень сайта, где лежат index.html и backend. Сохраняйте вложенные пути; разрешите замену перечисленных файлов. config.php, база и существующие PDF в пакет не входят.
3. Войдите существующей учётной записью администратора и откройте admin-migration.html (также доступна из раздела Система).
4. Нажмите «Импортировать метаданные». Manifest содержит 51 выпуск: 31 ready, 11 needs_recovery и 9 duplicate_conflict. Уже существующие строки не изменяются. Если уникальная идентичность занята нативным выпуском, журнал покажет conflicts; автоматически объединять записи нельзя.
5. Нажимайте «Импортировать следующую партию PDF». Каждый запрос обрабатывает максимум одну PDF с таймаутом скачивания 18 секунд. Действия не запускаются автоматически. Статусы сохраняются в базе, можно закрыть страницу и продолжить позднее. После сетевого обрыва сначала обновите статус. failed повторяются после оставшихся ready.
6. Проверьте архив, откройте несколько PDF и создайте новую резервную копию.

Требования: существующая актуальная схема backend/schema.sql (legacy-поля, уникальные ключи и system_audit_log), PHP 8.1+, PDO MySQL, cURL, запись в backend/storage/archive. Используется существующий app.archive_dir; штатное значение — backend/storage/archive. На сервере сохраняются только PDF, прошедшие %PDF-, точный размер и SHA-256 из manifest. Проверка SSL отключена исключительно для HTTPS chspu.ru, редиректы не выполняются. needs_recovery/duplicate_conflict получают только первоначальные метаданные; PDF и существующие записи этих статусов не изменяются.

Старый backend/maintenance/import-legacy.php больше не выполняет импорт: после проверки admin-сессии возвращает 410. Все записи выполняются через backend/api/legacy-migration.php с admin-сессией, CSRF и общей файловой блокировкой. GET возвращает счётчики и последнее действие из журнала аудита. В ZIP нет секретов, конфигурации сервера, тестов или workflow-файлов.
