# Известия ЧГПУ — новый сайт научного журнала

Стартовый прототип нового электронного журнала Чеченского государственного педагогического университета.

## Что уже заложено

- строгая академическая главная;
- текущий выпуск и архив;
- карточка научной статьи;
- форма подачи рукописи;
- кабинет редакции со статусами рукописей;
- адаптивная верстка для телефона и компьютера.

## Следующие этапы

1. Перенос архива и метаданных с действующего сайта ЧГПУ.
2. Подключение базы данных и хранилища файлов.
3. Авторизация редакции и разграничение ролей.
4. Реальный workflow: подача → проверка → рецензирование → доработка/отказ/принятие → публикация.
5. Публикация статей как HTML + PDF и формирование выпусков.

Источник исторических материалов: https://chspu.ru/izvestiya-chgpu/
