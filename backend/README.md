# Backend «Известия ЧГПУ»

Совместимый вариант для Beget: PHP 8.x + MySQL/MariaDB.

## Развёртывание

1. Создать MySQL-базу и пользователя в Beget.
2. Импортировать `schema.sql`.
3. Скопировать `config.example.php` в `config.php` и заполнить реквизиты.
4. Создать каталог `backend/storage/uploads` и дать PHP право записи.
5. Создать первого администратора через одноразовый `api/create-editor.php`.
6. Сразу удалить `api/create-editor.php`.
7. Подключить frontend к API по пути `/backend/api`.

## Уже реализовано

- подача рукописи;
- загрузка DOC/DOCX + PDF;
- SHA-256 файлов;
- отслеживание статьи по секретной ссылке без регистрации автора;
- вход редактора по защищённой PHP-сессии;
- список рукописей;
- карточка рукописи;
- смена статусов;
- история действий;
- таблицы выпусков и опубликованных статей.

## Безопасность

- SQL только через PDO prepared statements;
- пароль хранится через `password_hash`;
- файлы получают случайные имена;
- типы/расширения/размер файлов проверяются;
- директория storage закрывается от прямого веб-доступа;
- `config.php` с паролем БД нельзя коммитить в GitHub.
